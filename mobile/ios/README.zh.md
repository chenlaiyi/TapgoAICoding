系统启动画面和应用内短暂启动页共用 ImageGen 生成的蓝色品牌角色插画，以浅冰蓝背景、居中的“点点够终端”标题、简短口号和底部标语排版。启动页在浅色和深色外观下保持一致。未配对欢迎页使用桌面端角色和语义颜色。“连接电脑”接受 Mac 或 Windows 的链接。

新对话页左上角使用无圆形背景的返回箭头。iOS 应用的原生“远程”首页显示当前 Mac 名称、电脑切换菜单、搜索、Host 置顶会话和按工作目录分组的真实会话；底部输入框打开独立的新对话页，显示电脑选择、可浏览或新建 Mac 文件夹并将其注册为项目的项目下拉菜单、当前 Mac 执行与分支提示，输入框固定在键盘上方，支持拖动收起键盘，集中显示权限、标明账号或 API 来源的模型名和可用余额，固定在输入框内的下排操作栏；模型与思考深度沿用这台 iPhone 上次为该 Mac 确认的选择；模型目录读取失败时显示不可用状态。下拉可刷新会话列表；连接异常显示重试。扫码或粘贴连接后自动显示 Mac 设置的电脑名称和 HTTPS 地址。在电脑菜单中可重命名当前电脑，仅修改这台 iPhone 上的显示名称；再次配对仍保留手机备注。未携带名称的旧链接使用域名。中间的“远程”菜单仅切换已配对 Mac；左上角菜单覆盖在对话列表上，提供优先级、按项目和按时间排序、最近优先、添加连接、设置和可用余额。深色远程控制设置页列出已配对电脑及当前连接开关，提供全部断开、添加连接、编写器偏好和手机备注修改；添加连接直接打开配对窗口，不移除当前 Mac。每台 Mac 可通过扫码、粘贴或 `dsh-mobile://?url=…` 深度链接导入带单进程 `token` 的 HTTPS 地址。连接列表和令牌保存在本设备 Keychain；原生首页和对话使用保留认证 Cookie 的 URLSession，并可复用 WebKit 的同源 Cookie；Web 会话 Cookie 保存在 WebKit。Web 视图仅能导航到选定来源。应用连接期间持续接收 Host 的审批和问题事件；即使停留在远程首页，也会显示确认卡，允许一次、拒绝、回答或转到电脑处理，Host 撤回时自动关闭。点会话行进入原生对话页，可查看紧凑标题栏、浅蓝色用户消息、按 DSH 阅读密度排版的 Markdown AI 回复，支持软换行、嵌套列表、任务项、长代码换行与窄屏表格；助手各阶段的文字按消息独立显示，当前流式消息完成后在原位置更新为完整正文；每轮结束后的最后一条回复显示复制、可撤回的赞/踩、从此回复分支新对话和本地时间、按单轮聚合且默认收起、点按后展开的推理与工具过程（包含 DSH 流记录）、实时回复；运行中用同一个主按钮切换发送与停止，可将补充提示词排队发送而不取消当前任务、模型、余额和权限操作固定在下排的输入框、可折叠推理、可复制代码块、简单表格和消息，并发送文字；Host 需要智能体无法独立做出的决定时，原生对话页会在输入框上方显示这条待确认请求，并通过同一条转发事件流作答：工具批准或沙箱升级提供“允许一次”和“拒绝”，提问或计划确认提供其自身选项，以及“其他”自由回答或跳过，两种卡片都可把请求交回 Mac 处理；这台 iPhone 不处于该对话期间到达的请求会留在 Mac 上保持待定，进入该对话时再显示。原生过程详情先展示完整调用参数和工具返回的文字，再单独折叠思考过程；长输出按需展开，可复制全文。关联到本会话任务的工具复用 Host 现有的非消耗式 `job.list` 与 `job.follow` 流，在工具返回前逐步显示输出；按 UTF-8 字节偏移续传并去重，每个任务最多保留 64 KiB 实时预览，当前对话最多缓存 32 个已结束任务的预览。截断、断线、停止和流读取失败均明确提示；未提供此能力的工具或 Host 仍展示最终返回。专用复杂结果和工作区功能仍在 DSH Web 中；“完整工作区”打开同一会话的 DSH Web 客户端，供文件、终端和其他高级能力使用。未配对时也使用原生“远程”首页，并从连接面板扫码或通过明确的剪贴板按钮粘贴链接。新对话和已有会话共用贴近输入框的加号菜单，提供相机、照片、文件、插件、方案模式和追求目标。输入区用小号辅助文字显示所选模型的简短名称，并标明“账号”或“API”；点按名称打开默认展开、按提供方分组的模型选择页，让当前选项可见，展示模型标识、当前选择和各模型的思考档位，选择档位时弹出档位选择，同一模型只换档位也会发出真实请求；确认期间禁用重复点击，成功后关闭，拒绝时保留面板和错误，结果不明时重连读取实际选择；旁边的盾牌仅展开权限菜单并标记当前预设。会话设置显示 Host 提供的模型和权限预设，选择后应用于当前会话；可用时还显示模型上下文剩余额度估计和本会话 token 用量。Host 提供账号余额时，输入框的模型右侧显示主要币种合计后的单个可用余额，以币种符号置于金额前并保留两位小数；会话设置页分别显示充值余额和赠金余额。

AI 正文按消息与步骤追加，保留多个文本块之间的段落边界；增量按顺序校验，缺口触发重新同步，完成文本作为最终正文替换同一消息，停止时保留 Host 已确认的部分回复。界面按帧合并增量更新，完成前显示“正在回复”。运行中 90 秒没有收到新帧时，在回复上方显示已等待的秒数，并提供停止和重新同步；心跳在 ping 未按时收到 pong 时判定连接已断开并自动重连。原生对话在读者停留于底部时跟随流式回复的实际末尾；向上翻阅保留阅读位置，并显示“回到最新”。悬浮输入卡、对话导航控件和快捷菜单在 iOS 26 使用系统玻璃材质，旧系统使用模糊材质；开启“降低透明度”时使用不透明表面。新对话和已有会话的输入文字与占位提示统一采用默认 15 点的较小文字样式，并随系统动态字体缩放。输入框位于键盘上方，窄屏时仍将模型、余额与权限和发送操作保持在下排，常用操作的点击区域至少为 44 点。发送期间显示进度；成功后仅清除提交后未改变的文字和已送达的附件，失败时保留草稿；请求超时只在结果不确定时提示未确认送达，并沿用同一提交标识，再次发送不会重复；带照片的提交使用更长的请求超时。新对话创建期间禁止重复提交，显示进度与可重试的原位错误，并保留草稿；操作区适配窄屏和动态字体，浅色、深色模式均使用语义配色。

在本目录运行 `xcodegen generate`，构建 `DshMobile` scheme。应用沿用 `com.devtools.terminalSimple` Bundle ID；签名和分发需要相应 Apple 开发者团队权限。 DEBUG 欢迎页夹具跳过 Keychain 访问。DEBUG UI 测试连接链接只保留在内存中，不覆盖设备 Keychain；DEBUG 版本启动时清理以前保存的 `.example` 测试链接，并恢复最近配对的真实 Mac。

每台 Mac 的 Host 都需要独立的 HTTPS 来源，转发到本机端口 19388。统一公网部署通过[桌面端共享中继](../../apps/desktop/README.zh.md)自动取得该来源：管理员只配置一次泛域名，每台 Mac 获得稳定的随机设备主机名，不再单独添加 DNS 记录。应用菜单提供带二维码和可复制认证链接的“连接手机”窗口；电脑名称默认取 macOS“电脑名称”，也可在窗口中修改。现有 `TAPGO_MOBILE_HTTPS_ORIGIN` 连接继续可用。桌面 Host 仍只监听本机，仅信任分配给自己的 HTTPS 主机；手机通过页面内目录浏览选择该 Mac 上的文件夹。

进程重启会轮换链接令牌。此前 WebKit 获得的 Cookie 可能在配置的有效期内继续使用；认证失效时，请从对应 Mac 再复制链接重新配对，已保存的电脑名称会保留。该链接允许访问 Harness 界面并执行命令，请勿外传。

原生对话流中断后，只要对话页仍打开，就按有界退避持续重连，恢复时读取 Host 快照。对话 WebSocket 单条消息上限为 32 MiB，以容纳较长会话的首次快照；连接日志只记录错误域、代码和关闭码，不记录链接令牌或消息内容。原生请求和确认事件流跨应用重启保留 Host 认证 Cookie；Cookie 仍有效时，Mac Host 重启无需重新配对。远程设置显示最近一次成功读取会话列表的时间；仅选中 Mac 不代表连接成功。
远程首页显示期间每 15 秒刷新一次会话状态；一次后台轮询失败仍保留最近一次成功结果和连接状态。前台对话与确认事件 WebSocket 每 20 秒发送保活 ping，避免代理关闭空闲连接；两条流的重连退避最多 30 秒。应用从后台返回且当前对话已断开时，立即尝试重连。
首批客户试用只支持 iPhone 竖屏；iPad 原生布局完成验证前不纳入 Xcode 目标设备。

iPhone 应用图标使用由 `apps/desktop/resources/dot-master.png` 派生的统一小点点形象；在仓库根目录运行 `node apps/desktop/scripts/render-brand-assets.mjs` 可重新生成。

原生设置分别显示账号余额和 DeepSeek 官方 API 余额，账号未登录时仍可查询 API 余额。API 查询使用已配对 Host 的配置凭据，手机不会接收 API Key。输入框余额随所选提供方切换：账号路由显示账号钱包，其他路由查询各自余额，不回退到账号钱包。凭据缺失、不支持查询或读取失败时显示余额不可用。返回前台、读取设置及对话轮次完成时刷新余额；更换电脑时清除上一台的金额。

连接管理为每台已配对电脑提供明确的编辑、删除入口，断开连接后仍可管理。编辑仅修改本手机显示的名称；连接信息变化时使用新链接重新配对。删除需要确认，只移除本手机保存的配对。编辑或删除其他电脑保留当前连接；删除当前电脑返回连接页面。

新会话和已有会话的模型、余额固定在输入框内下排，位于权限与发送/停止主按钮之间；展开输入框时，键盘展开和收起不会改变下排控件的相对位置。滚动阅读时，无附件且未启用方案或目标模式的输入卡收成单行玻璃条；点输入区恢复完整编辑和原草稿，紧凑状态的加号菜单仍可展开收起。

回复完成后，输入卡内展示配对 Host 提供的最多三条下一步提示词。每轮首次收到建议时，第一条预填到空输入框；切换建议会替换尚未编辑的推荐文字，用户已编辑的草稿则保留并追加所选建议。主动清空后，重放不会再次填入。保留已选照片，不会自动发送。新轮次移除旧建议。需同时更新手机应用和配对 Host 以启用[生成器](../../packages/session/next-prompts/README.zh.md)；旧 Host 不提供建议。任务执行期间，唯一主按钮在空输入时显示停止，有文字或附件时显示发送并将补充提示词排队；长按发送可保留草稿并停止当前任务。发送和停止确认期间显示不可重复点击的进度状态。过程预览最多展示四行推理和最近三项操作，始终提供收起入口；完整实时详情默认展开为大面板，先展示实时日志，再展示调用参数；关闭和全部收起操作固定可用，新输出不会重新展开已收起的工具。日志采用限高视口，可暂停跟随和回到最新，手动滚动会暂停跟随；停止后保留已收到的部分输出。实时预览仅在当前对话进程中保留，离开对话后释放，工具最终返回仍在历史记录中。查看过程时暂停对话的自动跟随。已停止、任务失败、等待处理、中断和输出达限分别标记，取消的工具显示已停止而非失败。Shell 工具按返回内容末尾的退出码或信号标记显示结果，即使工具调用正常返回，非零退出码仍计为操作失败。新对话模型菜单标记当前选择。原生页头跟随 Host 标题投影，包括新任务开始后生成的标题。

远程首页以可横向滚动的快捷栏展示已配对的 Mac。轻点即可切换当前连接；勾选标记表示当前选择，不代表其他 Mac 在线。首页出现时，当前电脑的快捷项会滚动到可见位置。

加号菜单在输入框操作栏上方展开，轻点外部可收起，空间不足或动态字体较大时可滚动。相机与照片选择会添加 JPEG 图片；文件入口选择本机或文件提供方的文档，发送时通过已认证的 Host 文件上传接口提交原始字节。提交前文件保留在手机上。读取、上传或命令失败时保留草稿及已有附件。方案模式通过 `/plan` 提交要求和附件，激活后可明确通过 `/plan off` 退出；追求目标通过 `/goal` 提交非空目标和附件；会话从 Host 投影基线及更新恢复目标内容与阶段，提供暂停、继续及确认后清除的操作。仅包含保留控制命令的目标在提交前被拒绝。Host 未提供命令时报告失败，不会改为普通对话发送。新对话重试复用已知创建成功的 Session。插件入口读取配对 Host 的真实 bundle 列表；启停可用 bundle 前需确认，因为会影响该电脑的所有对话。结果区分已生效、已保存但需要重启和被覆盖；结果不明时只回查列表，不自动重试写入。

回复反馈使用 Host 的消息反馈接口与版本校验，成功后更新选择；拒绝时保留原状态，提交结果不明时只读取回查，不自动重放写入。分支以当前回复所在轮次的结束事件为截止点创建新对话，保留来源上下文，不自动发送；创建结果不明时提示回会话列表核对并禁止重复创建。`workspace/changes` 事件对应的文件胶囊显示真实文件总数和增删行数，打开后可查看逐文件差异；预览超出 Host 保留期、文件过大或二进制文件均明确提示；新分支不保留来源会话的文件预览，失效预览不提供重试，分支页头明确标记继承上下文。未收到变更事件时不显示文件胶囊。
