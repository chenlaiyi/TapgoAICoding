# Tapgo iOS

[English](README.md) | 中文

原生启动页、短暂的应用内启动页与未配对欢迎页统一展示桌面端的小点点形象、粗体“点点够终端”、“点点够，一切都一点点变好！”和“组装无限可能，共探智能上限”。主次文字使用系统语义配色，随浅色、深色模式切换。“连接电脑”支持 Mac 或 Windows 的连接链接。

新对话页左上角使用无圆形背景的返回箭头。iOS 应用的原生“远程”首页显示当前 Mac 名称、电脑切换菜单、搜索、Host 置顶会话和按工作目录分组的真实会话；底部输入框打开独立的新对话页，显示电脑选择、可浏览或新建 Mac 文件夹并将其注册为项目的项目下拉菜单、当前 Mac 执行与分支提示，输入框固定在键盘上方，并提供明确的收起键盘按钮，并在同一行显示权限、无供应商前缀的模型名和可用余额；模型沿用这台 iPhone 上次为该 Mac 使用的型号；模型目录读取失败时显示不可用状态。下拉可刷新会话列表；连接异常显示重试。扫码或粘贴连接后自动显示 Mac 设置的电脑名称和 HTTPS 地址。在电脑菜单中可重命名当前电脑，仅修改这台 iPhone 上的显示名称；再次配对仍保留手机备注。未携带名称的旧链接使用域名。中间的“远程”菜单仅切换已配对 Mac；左上角菜单覆盖在对话列表上，提供优先级、按项目和按时间排序、最近优先、添加连接、设置和可用余额。深色远程控制设置页列出已配对电脑及当前连接开关，提供全部断开、添加连接、编写器偏好和手机备注修改；添加连接直接打开配对窗口，不移除当前 Mac。每台 Mac 可通过扫码、粘贴或 `dsh-mobile://?url=…` 深度链接导入带单进程 `token` 的 HTTPS 地址。连接列表和令牌保存在本设备 Keychain；原生首页和对话使用保留认证 Cookie 的 URLSession，并可复用 WebKit 的同源 Cookie；Web 会话 Cookie 保存在 WebKit。Web 视图仅能导航到选定来源。应用连接期间持续接收 Host 的审批和问题事件；即使停留在远程首页，也会显示确认卡，允许一次、拒绝、回答或转到电脑处理，Host 撤回时自动关闭。点会话行进入原生对话页，可查看紧凑标题栏、浅蓝色用户消息、按 DSH 阅读密度排版的 Markdown AI 回复，支持软换行、嵌套列表、任务项、长代码换行与窄屏表格；同一轮助手文字合并显示且只保留一个复制操作、按单轮聚合且默认收起、点按后展开的推理与工具过程（包含 DSH 流记录）、实时回复；运行中发送按钮切换为停止并调用会话取消接口、聚焦后在键盘上方展开模型、余额和权限操作的输入框、可折叠推理、可复制代码块、简单表格和消息，并发送文字；Host 需要智能体无法独立做出的决定时，原生对话页会在输入框上方显示这条待确认请求，并通过同一条转发事件流作答：工具批准或沙箱升级提供“允许一次”和“拒绝”，提问或计划确认提供其自身选项，以及“其他”自由回答或跳过，两种卡片都可把请求交回 Mac 处理；这台 iPhone 不处于该对话期间到达的请求会留在 Mac 上保持待定，进入该对话时再显示。复杂工具结果和工作区功能仍在 DSH Web 中；“完整工作区”打开同一会话的 DSH Web 客户端，供文件、终端和其他高级能力使用。未配对时也使用原生“远程”首页，并从连接面板扫码或通过明确的剪贴板按钮粘贴链接。原生对话页的加号操作面板可直接添加照片，添加文件则打开完整工作区。输入区用小号辅助文字显示所选模型的简短名称，不带供应商前缀；点按名称仅打开模型选择页，旁边的盾牌仅展开权限菜单并标记当前预设。会话设置显示 Host 提供的模型和权限预设，选择后应用于当前会话；可用时还显示模型上下文剩余额度估计和本会话 token 用量。Host 提供账号余额时，输入框的模型右侧显示主要币种合计后的单个可用余额，以币种符号置于金额前并保留两位小数；会话设置页分别显示充值余额和赠金余额。

在本目录运行 `xcodegen generate`，构建 `DshMobile` scheme。应用沿用 `com.devtools.terminalSimple` Bundle ID；签名和分发需要相应 Apple 开发者团队权限。 DEBUG 欢迎页夹具跳过 Keychain 访问。DEBUG UI 测试连接链接只保留在内存中，不覆盖设备 Keychain；DEBUG 版本启动时清理以前保存的 `.example` 测试链接，并恢复最近配对的真实 Mac。

每台 Mac 的 Host 都需要独立的 HTTPS 来源，转发到本机端口 19388。统一公网部署通过[桌面端共享中继](../../apps/desktop/README.zh.md)自动取得该来源：管理员只配置一次泛域名，每台 Mac 获得稳定的随机设备主机名，不再单独添加 DNS 记录。应用菜单提供带二维码和可复制认证链接的“连接手机”窗口；电脑名称默认取 macOS“电脑名称”，也可在窗口中修改。现有 `TAPGO_MOBILE_HTTPS_ORIGIN` 连接继续可用。桌面 Host 仍只监听本机，仅信任分配给自己的 HTTPS 主机；手机通过页面内目录浏览选择该 Mac 上的文件夹。

进程重启会轮换链接令牌。此前 WebKit 获得的 Cookie 可能在配置的有效期内继续使用；认证失效时，请从对应 Mac 再复制链接重新配对，已保存的电脑名称会保留。该链接允许访问 Harness 界面并执行命令，请勿外传。

原生对话流中断后，只要对话页仍打开，就按有界退避持续重连，恢复时读取 Host 快照。对话 WebSocket 单条消息上限为 32 MiB，以容纳较长会话的首次快照；连接日志只记录错误域、代码和关闭码，不记录链接令牌或消息内容。原生请求和确认事件流跨应用重启保留 Host 认证 Cookie；Cookie 仍有效时，Mac Host 重启无需重新配对。远程设置显示最近一次成功读取会话列表的时间；仅选中 Mac 不代表连接成功。
远程首页显示期间每 15 秒刷新一次会话状态；一次后台轮询失败仍保留最近一次成功结果和连接状态。前台对话与确认事件 WebSocket 每 20 秒发送保活 ping，避免代理关闭空闲连接；两条流的重连退避最多 30 秒。应用从后台返回且当前对话已断开时，立即尝试重连。
首批客户试用只支持 iPhone 竖屏；iPad 原生布局完成验证前不纳入 Xcode 目标设备。

iPhone 应用图标使用由 `apps/desktop/resources/dot-master.png` 派生的统一小点点形象；在仓库根目录运行 `node apps/desktop/scripts/render-brand-assets.mjs` 可重新生成。

扫码页在相机权限被拒绝或相机不可用时提供取消和返回粘贴链接入口。相机启动和停止使用同一串行队列，关闭扫码页后延迟返回的权限结果不会启动相机。账户请求上报已安装应用的版本号。

首页和对话页可见时每 15 秒刷新可用余额，对话回合结束后也会刷新；返回前台后恢复刷新。取消的请求不会覆盖连接状态。

随包隐私清单以 CA92.1 声明 UserDefaults 仅用于保存本应用的模型和界面偏好。

远程设置控制启动时恢复连接、编写器内上下文用量显示，以及后续消息的排队或立即发送方式。回合运行时，有草稿显示发送，空草稿显示停止。
