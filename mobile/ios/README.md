Generate the Xcode project with `xcodegen generate` in this directory and build the `DshMobile` scheme. The app uses the existing `com.devtools.terminalSimple` bundle ID; signing and distribution require access to its Apple developer team. DEBUG UI-test pairing links stay in memory and never replace the device Keychain entry. A DEBUG build removes previously saved `.example` test links on launch and restores the last real paired Mac.

Each Mac's Host needs a distinct HTTPS origin forwarded to its loopback port 19388. A managed public deployment obtains that origin automatically from the [Desktop shared relay](../../apps/desktop/README.md): the administrator configures one wildcard DNS zone, and each Mac receives a stable random device hostname without an individual DNS record. The application menu offers **Connect iPhone** with a QR code and copyable authenticated link; the computer name defaults to macOS Computer Name and can be changed there. Existing `TAPGO_MOBILE_HTTPS_ORIGIN` connections remain usable. The Desktop Host stays bound to loopback, trusts only its assigned HTTPS authority, and uses in-page directory browsing so the phone can choose folders on that Mac.

A process restart rotates the URL token. A WebKit cookie issued earlier may remain valid until its configured expiry. Re-pair that Mac with a fresh link when authentication expires; its saved name is retained. Do not share the link; it grants access to the Harness UI and command execution.

The native conversation retries interrupted follow streams with bounded backoff for as long as the conversation stays open and restores the Host snapshot after reconnecting. The chat WebSocket allows messages up to 32 MiB for large initial snapshots; connection logs contain only error domains, codes, and close codes, never pairing tokens or message content. Native requests and approval streams retain the Host authentication cookie across app restarts, so a Mac Host restart does not require pairing again while that cookie remains valid. Remote settings show the last successful session-list check; selecting a Mac alone does not count as a live connection.
The Remote home refreshes session status every 15 seconds while visible, retaining the last successful result and connection indicator through one failed background poll. Foreground conversation and confirmation WebSockets send a ping every 20 seconds to keep idle proxy connections open. Both streams retry with backoff capped at 30 seconds; returning to an open conversation after backgrounding retries immediately when disconnected.
The initial customer trial targets iPhone in portrait orientation; the Xcode target excludes iPad until its native layouts are verified.

The iPhone app icon uses the shared dot mascot generated from `apps/desktop/resources/dot-master.png`; regenerate it with `node apps/desktop/scripts/render-brand-assets.mjs` from the repository root.
