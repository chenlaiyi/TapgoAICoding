## 折叠行标题直接显示命令/文件路径内容（对齐 Codex 实机）

- Codex 实机：折叠行显示具体命令（如「已运行 git status --short; sed -n ...」）而非重复「运行了命令」。
- Tapgo 之前折叠行只显示标签「运行了命令」/「思考过程」/「读取内容」不显示具体内容。
- 现在折叠行标题直接用 `display.text`（含命令 / 文件路径），reasoning 保持「思考过程」。
- 同步更新隐私测试（现在折叠行允许显示命令内容）。
