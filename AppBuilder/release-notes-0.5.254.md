# Tapgo AICoding 0.5.254

## 对话渲染三次对齐 Codex

### 1. 回合摘要行常显 + 分隔线

此前摘要行只在打开「显示工作过程」时才出现。现在**每个回合都有一行摘要**，与 Codex 一致：

- 进行中：`已处理 2分钟 22秒 ›`（每秒实时更新）
- 已完成：`用时 3分钟 21秒 ›`
- 摘要行下方新增**横贯整宽的分隔线**，把回合内容与下一回合分开。
- 没有工作细节可展开时，只显示时长、不显示箭头。

「显示工作过程」这个开关的语义相应收窄为：**工作细节默认是否展开**（不再影响摘要行是否出现）。

### 2. 代码块：语法着色 + 换行切换

- **语法着色**：代码块按 注释 → 字符串 → 关键字 → 数字 的优先级着色，覆盖 Swift / Python / JS / TS / Shell / JSON / SQL / Go / Rust / YAML 等。实现为内置的正则分段器，**不引入任何第三方依赖**。实测效果：`func` 紫色、`"Hello, World!"` 橙色。
- **自动换行切换**：标题栏新增换行开关（默认关，长行水平滚动以保持代码列对齐），与 Codex 代码块的两个按钮一致。

## 验证

- 摘要行 + 分隔线：实机截图确认。
- 代码块着色与两个按钮：通过实际发送一条含 Swift 代码块的请求确认。
- 全量回归通过；剩余失败为存量环境项（SSH 集成假 IP 超时、缺 auth.json 的集成跳过），与本版无关。
