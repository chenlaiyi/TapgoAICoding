# Tapgo AICoding 0.5.91

本版继续收紧消息输出，使阅读节奏与 Codex 桌面端更接近。

- 默认使用自然、连贯的短段落，仅在明显提升扫读效率时使用标题、列表或表格，减少机械化报告模板。
- 进行中过程改为中性文字与轻量进度提示；完成后以“已处理 + 时长”折叠过程，普通工具事件不再按类别大面积着色。
- 文件改动在回复后保留独立摘要卡，显示增删行数并默认预览 3 个文件，仍可直接查看具体差异。
- Markdown 表格改为平面分隔样式，支持单元格内加粗、行内代码和链接，避免显示原始标记。
- 用户消息操作按钮改为悬停出现；引用、代码块和流式光标进一步降低装饰噪声。
