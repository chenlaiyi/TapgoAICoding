# Tapgo AICoding 0.5.245

## 工具聚合分组:连续命令折叠成「终端 · N 个命令」

- 同一回合里连续多个命令折叠成一行「**终端 · N 个命令**」，头部带 chevron，**默认收起**，点 > 展开看到每条命令及结果。
- 头部状态后缀：进行中显示「· 进行中」，含失败命令时显示「· 失败」，其余不显示。
- 展开后按时间顺序列出：每条命令的状态图标（succeeded 绿 ✓、failed 红 ✗、running 蓝播放、awaitingApproval 虚线圈、denied 手形）+ 命令等宽文本 + 失败时附 stderr 前 240 字摘要。
- 单条命令不折叠，仍走单行 activity 形态以避免样式退化。
- 文件改动批次沿用既有 `fileBatch` 形态不变（ZCode changesGroup 的语义已覆盖）。

实据来源：ZCode.app 应用包源码（executeGroup JSX）+ 你提供的折叠/展开实机截图。
