# Tapgo AICoding 0.5.106

全面升级消息输出样式和内容，更接近 Codex 桌面端的阅读节奏。

- 节奏收紧：段落 / 列表 / 表格的行距与段距下调，markdown 块更紧凑、对话更易扫读。
- 思考合并：连续 reasoning / reasoningSummary 合并到同一行 `思考过程 · N 字符`，点击展开完整正文；单段思考保留极简标签。
- 用户气泡更克制：padding 收紧、增加细描边，不再像聊天贴纸。
- 状态徽章轻量化：替换为低饱和度小色点 + 描边胶囊，避免彩色堆叠。
- 行内代码底色更柔和：`#EFEFF1` / `#2E2E2F`，与正文对比更自然。
- 流式光标内联：2pt 胶囊紧贴最后一段，不再独立成行。
- 工具 / 查阅汇总：连续搜索类工具合并到 `查阅 · N 搜索, M 列表`；多段思考同样合并。
- 渲染层加 `summaryText` 通道：聚合行携带完整正文与字符数，UI 据此显示字符徽标和展开内容。
