# Tapgo AICoding 0.5.92

本版以 Codex Desktop 实机窗口为视觉真值，全面收紧消息阅读与流式输出界面。

- 深色层级改为 Codex 的近黑消息画布、深灰侧栏与低对比选中态，侧栏和消息列按同视口比例重新对齐。
- 流式过程只保留安静的单行进度；移除扫光动画、思考紫色与工具类别色，真实失败仍保留红色提示。
- 完成态操作改为紧凑图标，不再常驻时间和长文字；时间、用量、时长继续可在提示中查看。
- 文件变更改为 Codex 式结果卡：单文件直接显示文件名与增删行，点击“审核”查看真实差异；多文件默认折叠，避免淹没正文。
- 输入框移除多余胶囊，权限与模型改为轻量文字控件，发送/停止改为圆形主动作，并降低空输入区高度。
- 保留 Markdown 正文、表格、列表、代码块、复制、反馈、排队发送、电脑操作与差异审核等原有能力。

验证：同一 1148 × 1344 视口与 Codex 实机并排复核通过；完整测试、Release 构建、Developer ID 深度签名及本机安装回读均纳入本次发布验收。
