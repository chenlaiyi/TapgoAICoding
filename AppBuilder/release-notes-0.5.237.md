# Tapgo AICoding 0.5.237

## composer 动作按钮与 placeholder 对齐 Codex 实机

- 发送/停止合并为单颗圆形动作按钮：空闲 = ↑ 发送，运行中 = ■ 停止（中断当前回合，排队消息保留）；运行中继续排队走 ⌘↩ / 回车，与 Codex 桌面端交互一致。
- 输入框 placeholder 对齐 Codex 2026-09-10 实机：「随意输入」（自进化会话保持「向自进化下达本轮指令…」覆盖）。
- 模型区移除运行中 mini spinner——Codex 模型区是静态文本，运行态由动作按钮形态表达。
