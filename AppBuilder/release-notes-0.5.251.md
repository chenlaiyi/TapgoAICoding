# Tapgo AICoding 0.5.251

本次跨越 0.5.247 → 0.5.251 五个未发布版本，一次性汇总。

## 新对话欢迎页对齐 Codex Desktop

- **八角形 Codex Logo**（顶部居中，Canvas 自绘 1.4pt 描边，中心短横呼应 `_`）。
- **标题改为「你想让我们在 <项目> 中构建什么?」**，项目名以虚线虚划线标注，可点击切换项目。
- **四张建议卡横排**：探索并理解代码 / 构建新功能、应用或工具 / 审查代码并提出修改建议 / 修复问题和失败；各配彩色 hierarchical 图标（蓝 / 紫 / 绿 / 橙），点击即把对应提示词填入输入框（不自动发送）。
- 移除旧的时段问候语 + 项目副行 + 胶囊横排形态。

## 输入框顶栏：项目 / 环境 / 分支三段 chip

- 三段并列于同一浅色圆角背景内，匹配 Codex Desktop 实机形态。
- **项目 chip**：点击切换项目。
- **环境 chip（本地 / 远程）**：本地或远程是项目属性，点击打开项目选择器切换。
- **分支 chip**：显示当前 git 分支，点击弹出本地分支列表并可直接切换（`git checkout`）；切换失败（如未提交改动冲突）弹窗回显 git 错误首行。远程项目无本地分支，该段自动隐藏。

## 额度环恢复新任务对话显示

- 新任务（欢迎页）对话重新可见额度圈；会话内同样保留。
- 欢迎态底栏维持精简：电脑控制 chip 仍在欢迎态隐藏，会话内按设置显示。

## 模型切换菜单与设置页同源

- 输入框模型菜单的数据源从内置目录切到 ProviderRegistry（与模型设置页 / 手机端 / `/model` 命令同源）。
- 在设置页把 DeepSeek 模型改为 V4.1 后，切换菜单立即同步；未配置 Key 的模型项禁用。

## 测试

- 全量回归通过；`MakeHistory parity` 860/0（含 Info.plist / project.yml 版本四源对齐）。
- 失败项均为存量远端 SSH 集成与 auth.json 环境性，与本批改动无关。
