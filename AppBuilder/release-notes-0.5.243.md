# Tapgo AICoding 0.5.243

## 会话内回合摘要与思考行对齐 ZCode 源码实据

- 回合摘要用词对齐 ZCode：完成 =「已工作 {时长}」，进行中 =「工作中 {时长}」，中断 =「已停止」；移除「· N 步」步数段（ZCode 无此段）。
- 思考行标签：「思考过程」→「思考」（进行中的「正在思考」保持不变）。
- 时长单位统一：「X 分钟」→「X 分」，全 App 生效（回合摘要 / 轨迹 / 历史）。
- 「调整方向」文案保持不变（以你提供的实机截图为准；ZCode 新版源码已改用「引导」，差异已记录在 EVOLUTION）。

实据来源：ZCode.app 应用包渲染层 i18n 表（chat.history.* / chat.reasoning.* / chat.summaryPanel.duration）。
