# Tapgo AICoding 0.5.236

## 输入框上方目标与排队对齐 Codex 实机

- 排队行与目标行合并为一张活动带卡（TaskActivityStrip）：排队在上、目标行最下贴近输入框；中间细分隔线。
- 目标行单行内联：转圈图标（运行时自转）+ 粗体「进行中的目标」+ 截断目标文本（点按展开全文）+ 计时；右侧垃圾桶 / 圆圈暂停 / 折叠角标（顺序与 Codex 实机一致）。
- 排队行对齐 Codex：text.append 头图 + 纯文本迷你预览缩略图 + 单行文本 + 「⤷ 调整方向」带文字按钮 + 垃圾桶 + ⋯ 菜单（编辑 / 清空）。
- 计时格式对齐 Codex 实机：「11h 39m 48s」（单位间带空格，小时位也显示秒）。
- 移除「待发送 · N 条」折叠头与 composer 叠压 hack；活动带可整体折叠为一行摘要。
- build-app.sh：修复 ad-hoc 修复路径下嵌套 helper 重签破坏外层密封导致发布中断的问题（v0.5.235 起 appcast 停更的根因）。
