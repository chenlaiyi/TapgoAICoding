# Tapgo AICoding 0.5.252

## 对话消息渲染对齐 Codex

本版修正了消息流的呈现基准 —— 参考对象是 **Codex**（`com.openai.codex`）实机，而不是此前的第三方客户端。

- **工具行改为概括短语**：命令执行不再把原始命令行铺进消息流，改为 Codex 式动词短语「**运行了命令**」（运行中「正在运行命令」，失败「运行了命令 · 执行失败」）。原始命令行仍完整保留在会话数据里，供展开详情、导出与诊断使用。
- **不再渲染「思考」行**：对齐 Codex 实测 —— 消息流里没有独立的思考行；此前的每条 reasoning 都会占一行，是"流水账感"的主要来源。
- **回合摘要文案对齐**：完成回合「已工作 X」→「**已处理 X**」；进行中「工作中 X」→「**正在思考**」。
- **时长单位对齐**：「1 分 5 秒」→「**1 分钟 5 秒**」。

## 顺带修复：命令折叠长期不生效

v0.5.245 引入的「终端 · N 个命令」折叠在真实会话里从未触发。根因是 `reasoning` 与 `commandExecution` 在聚合层互相冲刷，真实轨迹总是"思考↔命令"交替，永远凑不出折叠条件。本版让 reasoning 不再打断命令序列，折叠恢复正常工作。

## 测试

- 全量回归通过；改动相关断言已同步，并新增「reasoning 夹在命令之间不再打断折叠」用例。
- 剩余失败均为存量环境项（SSH 集成使用保留网段假 IP、缺 auth.json 的集成跳过），与本版无关。
