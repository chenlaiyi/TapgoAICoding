# Tapgo AICoding 0.5.241

## 任务行时间四段与状态指示对齐 ZCode 源码实据

- 相对时间改为 ZCode 精确四段：<1 分钟=刚刚、<60 分钟=N分、<24 小时=N小时、≥24 小时=N天（废弃「今天/昨天」段）。
- 运行中的会话：标题左侧显示旋转 spinner（ZCode 的 loading 态）——修正上一版把蓝点误用于运行中的问题，蓝点在 ZCode 里是「未读」标记。
- 失败的会话：标题左侧红点，右侧时间保留（不再用感叹号图标顶掉时间）。
- 等待确认的会话：右侧显示绿色小徽章「等待确认」，与时间并存（对应 ZCode permissionTag）。
- 项目组行折叠箭头的 hover 显隐经核对已与 ZCode 分节头一致，无需改动。

实据来源：ZCode.app 应用包渲染层源码（og() 时间函数 / rbe() 状态函数 / 任务行 JSX）。

## 测试

- 全量回归 3145 通过（12 个失败均为存量远端集成环境问题，与本改动无关）。
- 本机真实界面回归：侧栏时间四段（刚刚/N分）与状态指示实机截图验证。
