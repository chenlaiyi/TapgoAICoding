# Tapgo AICoding 0.5.206

## 修复：DeepSeek 欠费（负余额）不再隐藏真实余额

- 实测发现：DeepSeek 账户欠费（如余额 -1.29）时 `/user/balance` 返回 `is_available=false` **且** `balance_infos` 里带真实负余额；旧逻辑把 `is_available=false` 一律当错误抛掉，导致底栏和弹窗都看不到余额。
- 现在：只要返回 `balance_infos` 就如实解析展示（含负数，如 `¥-1.29 CNY`），让你直接看到需要充值；仅当响应完全没有余额数据时才报错，且错误文案明确提示「通常为余额不足/欠费，请充值」。
- 新增负余额解析回归用例。
