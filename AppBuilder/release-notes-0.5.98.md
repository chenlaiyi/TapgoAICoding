# Tapgo AICoding 0.5.98

- 手机 Web Remote 的模型选择从静态展示升级为真实切换：按供应商分组展示 ProviderRegistry 模型，标记当前模型，并对新建任务立即生效。
- 未配置 API Key 的模型在手机端明确标为“未配置”且不可选择；Web 状态只下发模型 ID、显示名和配置状态，不会暴露 API Key 或供应商端点。
- 电脑操作抽屉新增远程控制总开关、屏幕录制和辅助功能三层状态，状态持续从 Mac 回读。
- 手机可立即关闭电脑控制；重新开启会在 Mac 上弹出确认，防止旧二维码链接绕过本机总开关。
- 手机可分别发起打开 Mac 的屏幕录制或辅助功能设置；macOS 系统授权仍必须由人在 Mac 上确认，Web 端无法绕过 TCC。
- 完善模型、权限和控制设置的鉴权路由、非法输入拒绝、状态快照与前端交互回归。
