# Tapgo AICoding 0.5.242

## 任务行 hover 操作按钮对齐 ZCode

- 侧栏任务行悬停时，右侧的状态指示（spinner/红点/徽章）与时间整体隐藏，显示两个操作按钮：**置顶/取消置顶** 与 **删除会话**——与 ZCode 任务行「hover 显操作、隐状态」的交互一致。
- 删除走既有的确认弹窗，不会直接删除；置顶即时生效（图钉图标随之切换）。
- 右键菜单的全部操作（复制/重命名/打开目录/附件等）保持不变。
- 「已置顶/最近任务」分节经核对属于 ZCode 的时间线组织视图，项目分组侧栏无此形态，维持现状。

实据来源：ZCode.app 应用包渲染层源码（任务行 JSX 的 hover 条件块与操作簇）。

## 测试

- 全量回归 3145 通过（12 个失败均为存量远端集成环境问题，与本改动无关）。
- 本机真实界面回归：默认态（无按钮、行选择正常）实机截图验证；hover 态为指针交互，以静态审查 + 构建验证。
