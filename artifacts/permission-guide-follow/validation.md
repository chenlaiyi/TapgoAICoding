# 授权引导跟随系统设置窗口验收

2026-09-05，版本 0.5.104。

- 窗口元数据定位系统设置，无需 Accessibility/Screen Recording 权限；0.2 秒轮询并响应应用/Space/显示器变化。
- 系统设置正下方居中，间隔 12pt；屏幕边缘自动限制，窗口下方空间不足时落在屏幕可见底边。
- 使用非激活 NSPanel 与 statusBar 层级，保持引导可见且不在跟随时切走焦点；没有可见目标时隐藏，关闭时释放定时器/观察者。
- 保留真实 AppKit Helper 文件拖拽。

验证：

- Core 全量 2807 passed / 0 failed（跳过远程 Harness 集成）；其中新增 12 项布局行为测试。
- 签名主 App / Helper 构建通过，均为 0.5.104。
- scripts/permission-guide-preview.sh 编译当前生产控制器与布局代码，仅移除模块导入以便独立链接；预览进程两项权限均为 false 时仍正常显示和跟随。
- 系统设置从 1345pt 高度缩为 864pt，浮窗从屏幕底边重新定位至窗口下方 12pt；窗口移动后浮窗保持对应位移。
- 窗口服务器回读引导层级 25，设置窗口层级 0；前台切换至其他普通应用后引导仍可见。
- 原生拖动控件从“等待拖动”到“拖拽已开始”，在引导自身空白处松手后为“目标未接受”，未向系统列表提交授权。
- 关闭浮窗后预览进程退出，窗口服务器中不再存在该引导窗口。
- 多显示器、屏幕边缘使用确定性布局测试覆盖；未在真实多显示器硬件逐项回归。
